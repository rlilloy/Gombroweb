01

Borgian Algebra

Write with open
alternatives

Inline variant branching — inspired by how Borges corrected his manuscripts: not by erasing, but by keeping multiple possibilities alive on the page simultaneously.

Right-click to resolve. Or never. Some sentences shouldn’t be decided.

Inline branchingNested sub-variantsStrikethrough visible
02

Burroughs Cut-up

Automated
cut-up

Burroughs and Gysin’s cut-up technique, built in. Splices a random paragraph from your own project into the current one — a controlled collision. Every source marked. Every shuffle undoable.

Use it when a paragraph feels stuck, when logic is the enemy.

Cut-up / shuffleSource markedUndoable
03

Sentence Mode

One sentence.
The rest is hidden.

Radical focus at the sentence level. Every time you write a period, Gombro isolates that sentence alone on screen. The rest of your text disappears.

This is how Hemingway thought about sentences. One true thing at a time.

Sentence isolationZero distraction
04

Schrödinger Mode

Text in
undecided state

Some text is neither one thing nor another — it hasn’t been decided. Schrödinger Mode marks those paragraphs. The ⚛ button shows how many are in quantum state. Gombro warns before compiling.

Quantum trackingExplorer badgeCompile warning
05

Version History

Every paragraph
has a silent timeline

Automatic, per-paragraph version history. No manual snapshots. Every state is saved silently. Navigate, compare, and restore any prior draft — any time, any paragraph.

Nothing is ever lost. Not the sentence you deleted at 2am.

Per-paragraphAutomaticRestore any version
06

Graph View

A map of
your manuscript

Visual graph of paragraphs as nodes. Draw connections manually. See how your project is actually structured — not how you thought it was. Multi-select opens all chosen paragraphs simultaneously.

Node graphManual connectionsMulti-select
07

Sessions

Improvisation,
not documents

Each writing session is an improvisation — a scene, a fragment, a drift. Title auto-generated from the first five words. Date stamped. Stored silently. Like a jazz session: you open the instrument, play, stop.

What you left behind is a session record: raw, alive, recoverable.

Auto-titledDate stampedPaths & forks
08

Collections

Saved searches.
Always current.

A collection stores the query, not the results. Every time you open it, it runs fresh — never stale. Your characters, motifs, hashtags: always findable, always up to date.
